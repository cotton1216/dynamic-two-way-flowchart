# dynamic-two-way-flowchart

科技风（HUD）双向动态流程图技能。用 SVG + CSS + SMIL 渲染「节点 + 连线 + 流向」，支持明暗主题、双向编号粒子、逻辑顺序播放和整轮循环，适合端到端调用链、架构流程与鉴权链路。

模板包含 HUD 网格、三阶段配色、编号徽章、核心节点脉动与主题切换。

![科技风动态流程图模板](assets/template.svg)

直接用浏览器打开 `assets/template.svg` 查看完整动画与右上角明暗切换按钮。作为图片引用时脚本不执行，仍可跟随系统主题；图片代理或静态渲染可能不播放动画。

## 功能特性

- 明暗 HUD 背景：网格点阵 + 四角角标 + 节点状态灯。
- 双向数据包：去程阶段色、返回灰蓝，连线编号与移动徽章编号一致。
- 三阶段配色：认证蓝 / 发现青 / 调用绿。
- 顺序动画：真实依赖约束、统一主时钟、完整流程结束后再循环。
- 场景语义：分支、缓存、并行、异步需要明确标注；未知先后不编造。
- 无障碍：`prefers-reduced-motion` 隐藏粒子并停止 CSS 脉动/呼吸，静态编号和图注保持可读。

## 使用方法

对 AI 说「用 dynamic-two-way-flowchart 画一个 XX 流程图」或「画一个带编号数据包的端到端调用链」。

| 类型 | 字段 |
| --- | --- |
| 节点 | id、标签、副标、角色（core / 普通） |
| 连线 | from、to、label、方向、阶段、步骤编号、依赖、场景/条件 |

输出自包含动态 SVG，默认编号并按逻辑依赖播放；正文和图内均须保留上面的完整时序声明。严格生命线、精确时间或完整并发时序应改用真正的时序图。

### 主题控制

不设置 `data-theme` 时跟随系统；根 SVG 上设 `data-theme="dark"` 或 `data-theme="light"` 时固定主题。浏览器直接打开 SVG 可点击按钮切换。内联 HTML 时将变量和选择器作用域限定在 SVG，避免影响宿主页面。

## 使用案例

### MCP 网关鉴权与调用

节点：用户、IdP、客户端、网关、权限中心、下游服务。认证完成后，将 `tools/list` 和 `tools/call` 分成两个场景，不宣称发现必然先于调用。调用只演示 allow 分支时写明假设；deny、缓存命中/未命中与异步审计另行标注条件。连线与粒子使用同一编号，整轮后再循环。

`assets/template.svg` 为 6 节点 13 步抽象示例，认证 1–3、发现 4–7、调用 8–13。两场景间隔只表示演示分段，不表示业务时间。

### 电商下单与异步落库

```bash
python scripts/example_ecom.py /tmp/ecom.svg
```

示例假定鉴权通过、支付成功，主链 1–10，支付成功后异步发货/落库使用 9a/9b；异步分支不阻塞客户端响应。内置几何自检检查连线、节点、编号标签与往返 lane。该示例固定深色，需要主题切换时参考模板。

### 导出 GIF

需要本机 Google Chrome 和 Pillow。显式传入完整流程周期，避免只截到前几个步骤：

```bash
python scripts/svg_to_gif.py assets/template.svg /tmp/template.gif 200 100 20000
python scripts/svg_to_gif.py /tmp/ecom.svg /tmp/ecom.gif 150 100 15000
```

导出时保留编号、场景说明与完整时序声明；为稳定配色先固定主题。
